# FD 调试软件

FD 是常用的 TTL 总线设备图形化调试工具，可用于扫描设备、修改 ID、修改波特率、读取反馈和设置部分参数。

## 适用场景

建议在以下场景使用 FD：

- 第一次确认设备是否在线。
- 不确定设备 ID。
- 需要修改 ID 或波特率。
- 不想先写代码，只想快速查看设备状态。
- 需要恢复或检查参数。

## 基本流程

```text
1. 连接 TTL Adapter (A)
2. 连接一个目标设备
3. 接入外部电源（执行器类设备必须）
4. 打开 FD 软件
5. 选择正确 COM 口和波特率
6. 扫描设备
7. 修改或读取参数
```

## 改 ID 建议

修改 ID 时，请总线上只连接一个设备。修改后重新扫描确认新 ID 生效。

## 常见问题

### 扫描不到设备

请检查：

- COM 口是否选对。
- 波特率是否选对。
- 设备是否有供电。
- TTL 总线线序是否正确。
- 是否连接了多个相同 ID 的设备。

### 能扫描到但无法运动

请检查：

- 执行器是否接入外部电源。
- 是否处于正确运行模式。
- 是否触发限位。
- 电流参数是否过低。
