# FD 调试软件

FD 是 Lygion TTL 总线设备的 Windows 图形化调试工具，可用于搜索设备、查看设备反馈、修改 ID、修改波特率、写入参数、测试执行器运动，以及完成编码器中位校准等操作。

本页以 SW69-TTL 舵轮模组的配置截图作为示例，说明 FD 软件的通用使用方法。不同产品的可配置参数可能不同，但连接、搜索、选择设备、进入编程页和保存参数的流程基本一致。

## 适用场景

建议在以下场景使用 FD：

- 第一次上电，确认设备是否在线。
- 不确定设备当前 ID 或波特率。
- 需要为多个 TTL 总线设备分配不同 ID。
- 需要修改运行模式、电流、相位、心跳保护等参数。
- 需要在写代码前测试电机、执行器或编码器是否正常。
- 需要对 TTL Encoder E02 等编码器执行中位校准。

!!! warning "FD 主要用于 Windows"
    FD 是面向 Windows 的图形化工具。Linux、macOS 或嵌入式控制器用户可以参考 [设备 ID 与波特率](device-id-and-baudrate.md)，通过 Python 或 C/C++ SDK 修改 ID 和参数。

## 下载与准备

[下载 FD 软件](../assets/files/FD.7z){ .md-button }

使用 FD 前请准备：

| 物料 | 用途 |
| --- | --- |
| Windows 电脑 | 运行 FD 软件 |
| TTL Adapter (A) 或兼容 TTL 转接板 | 将电脑 USB 串口转换为 Lygion TTL 总线 |
| USB Type-C 数据线 | 连接电脑和 TTL Adapter (A) |
| 外部电源 | 给步进电机驱动器、舵机、轮式模组等执行器供电 |
| 目标 TTL 总线设备 | 需要配置或测试的设备 |

!!! note "仅 USB 供电通常不够"
    TTL Adapter (A) 的 USB 连接只负责通信和转接。电机驱动器、舵机、轮毂电机等执行器类设备通常必须接入外部电源，否则可能可以搜索到设备，但无法正常运动。

## 基本连接

调试单个设备时，推荐按下面的方式连接：

```text
电脑 USB
  │
TTL Adapter (A)
  │
TTL 总线设备
  │
外部电源（执行器类设备需要）
```

以 SW69-TTL 的转向步进电机驱动器为例，调试时可以将 TTL Stepper Driver (A) 连接到 TTL Adapter (A)，同时接入电机线和外部电源。

![FD wiring example](../reference/modules/sw69-ttl/assets/change_id_connection.webp){ .img-rounded }

如果要同时连接多个设备，可以使用 Hub 扩展总线。但在修改 ID、波特率或关键参数时，建议先只连接一个目标设备，避免误改其它设备。

![Multiple device wiring example](../reference/modules/sw69-ttl/assets/wiring.webp){ .img-rounded }

## 第一次打开 FD

1. 解压 FD 软件压缩包。
2. 将 TTL Adapter (A) 连接到电脑。
3. 在 Windows 设备管理器中确认串口号，例如 `COM3`、`COM5`。
4. 打开 FD 软件。
5. 在串口位置选择对应的 COM 口。
6. 将波特率设置为设备当前波特率。常见默认值为 `1000000`。
7. 点击 `打开`，打开串口。

![FD serial settings](../reference/modules/sw69-ttl/assets/fd_01_cn.webp){ .img-rounded }

!!! tip "找不到串口时"
    请先确认 USB 数据线不是只能充电的线；如果 Windows 没有识别出串口，请检查驱动、USB 接口和 TTL Adapter (A) 是否正常连接。串口查找方法可参考 [查找串口设备](find-serial-port.md)。

## 搜索设备

打开串口后，点击 `搜索`。FD 会在当前波特率下搜索总线中的设备，并把搜索到的设备显示在左侧列表中。

![FD search](../reference/modules/sw69-ttl/assets/fd_02_cn.webp){ .img-rounded }

搜索到设备后：

1. 点击 `停止`，停止持续搜索。
2. 在左侧设备列表中选择目标设备。
3. 观察设备名称、ID 和状态是否符合预期。

常见设备名称示例：

| 设备名称 | 常见产品 |
| --- | --- |
| `TTL_SD01` | TTL Stepper Driver (A)、步进电机驱动器 |
| `TTL_E02` | TTL Encoder E02、带 E02 编码器的同步轮或关节模组 |

!!! warning "同一总线不要出现重复 ID"
    如果两个设备使用相同 ID，它们会同时响应同一条指令，可能导致搜索异常、读数异常或多个设备同时运动。新设备第一次配置时，请一次只连接一个。

## 修改设备 ID

修改 ID 是 FD 最常用的操作。建议先为每个设备规划唯一 ID，再逐个连接设备并写入。

推荐流程：

```text
1. 总线上只连接一个待配置设备
2. 打开 FD 并搜索设备
3. 停止搜索
4. 选择目标设备
5. 进入“编程”页面
6. 选择参数“ID”
7. 输入新的 ID
8. 点击“保存”
9. 重新搜索，确认新 ID 生效
```

![FD set ID](../reference/modules/sw69-ttl/assets/fd_03_cn.webp){ .img-rounded }

!!! danger "不要把“ID”和“从 ID”混淆"
    修改设备自身 ID 时，应选择参数 `ID`。`从 ID` 不是常规改 ID 操作使用的参数，除非对应产品文档明确要求，否则不要修改。

修改成功后，建议断开设备再重新上电，并再次点击 `搜索` 确认设备以新 ID 出现在列表中。

## 修改波特率

波特率决定上位机与设备的通信速度。同一条 TTL 总线中的设备必须使用相同波特率，否则会出现部分设备无法搜索或无法通信的问题。

修改波特率时请遵循：

1. 一次只连接一个目标设备。
2. 在当前波特率下搜索到设备。
3. 进入 `编程` 页面。
4. 选择波特率相关参数。
5. 写入新波特率并保存。
6. 关闭串口。
7. 将 FD 的波特率切换为新值。
8. 重新打开串口并搜索确认。

!!! note "常见默认波特率"
    Lygion TTL 总线设备常见默认波特率为 `1000000`。如果设备搜索不到，可以尝试在 FD 中切换常见波特率后重新搜索。

## 读取和保存参数

不同设备在 `编程` 页面中会显示不同参数。常见参数包括：

| 参数 | 常见用途 |
| --- | --- |
| `ID` | 设置设备 ID |
| `波特率` | 设置通信速度 |
| `运行模式` | 切换位置模式、速度模式等工作方式 |
| `驱动器相位` | 匹配步进电机接线和旋转方向 |
| `心跳保护时间` | 通信中断后自动停止，降低失控风险 |
| `电流` / `扭矩` | 设置执行器输出能力 |

以 SW69-TTL 的行走轮驱动器为例，作为车轮连续旋转时通常需要配置：

| 参数 | 示例值 | 说明 |
| --- | ---: | --- |
| `ID` | `12` | 为行走轮驱动器分配唯一 ID |
| `驱动器相位` | `152` | 匹配 DW69 行走轮驱动参数 |
| `运行模式` | `1` | 速度模式，用于车轮连续旋转 |
| `心跳保护时间` | `20` | 单位通常为 `100 ms`，即约 `2 s` |

![FD parameter editing](../reference/modules/sw69-ttl/assets/fd_11_cn.webp){ .img-rounded }

保存参数后，建议对设备断电重启，再重新搜索确认参数是否生效。部分驱动类参数需要重启后才会可靠生效。

## 调试执行器运动

执行器类设备可以在 FD 的 `调试` 页面中做基础运动测试。测试前请确认：

- 执行器已经接入外部电源。
- 机械结构不会夹手或碰撞。
- 轮子、履带或关节已经离开桌面，避免突然运动带动整机移动。
- 电流、速度和加速度先使用保守值。

以 TTL Stepper Driver (A) 驱动的步进电机为例，可先使用：

| 参数 | 建议起始值 | 说明 |
| --- | ---: | --- |
| 加速度 | `15` | 调试时比较平缓 |
| 速度 | `400` 或更低 | 先从低速开始测试 |
| 扭矩 / 电流参数 | `200` | 对应相电流约 `1.32 A`，以实际产品说明为准 |

![FD motor test](../reference/modules/sw69-ttl/assets/fd_04_cn.webp){ .img-rounded }

如果设备被配置为速度模式，例如作为车轮连续旋转使用，点击 `设置` 后电机会开始转动。若启用了心跳保护，而上位机没有继续发送控制指令，设备会在设定时间后自动停止。

![FD wheel test](../reference/modules/sw69-ttl/assets/fd_12_cn.webp){ .img-rounded }

!!! tip "先低速、低电流测试"
    首次调试不要直接使用高速或大电流参数。先确认方向、模式和限位都正确，再逐步提高速度、加速度和输出电流。

## 编码器中位校准

部分产品带有 TTL Encoder E02，例如 SW69-TTL 的转向同步轮、DM42-G7220-E02 关节执行器等。中位校准用于定义机械零点，后续程序中的 `0°` 或中位位置通常以该校准点为基准。

典型流程：

1. 让关节或同步轮处于可手动调整状态。
2. 将机构转到期望的机械中位。
3. 在 FD 中搜索并选择 `TTL_E02`。
4. 进入 `编程` 页面。
5. 点击 `中位校准`。
6. 出现成功提示后确认。
7. 切换到 `调试` 页面，确认当前位置读数约为 `2047` 或 `2048`。

![Encoder center position](../reference/modules/sw69-ttl/assets/cali_01.webp){ .img-rounded }

![FD encoder calibration](../reference/modules/sw69-ttl/assets/fd_07_cn.webp){ .img-rounded }

![FD encoder readback](../reference/modules/sw69-ttl/assets/fd_08_cn.webp){ .img-rounded }

!!! note "中位校准会保存到编码器"
    中位校准参数会保存到编码器内部。正常使用时不需要每次上电都重新校准，只有在重新装配、更换同步轮、调整机械零点或读数明显不符合预期时才需要再次校准。

## 多设备配置建议

当一个系统中有多个 TTL 总线设备时，推荐先规划 ID 表，再逐个配置。

以单个 SW69-TTL 舵轮为例，可以分配：

| 功能 | 设备类型 | 示例 ID |
| --- | --- | ---: |
| 转向编码器 | `TTL_E02` | `10` |
| 转向电机驱动器 | `TTL_SD01` | `11` |
| 行走轮电机驱动器 | `TTL_SD01` | `12` |

多个模组可以继续递增：

| 模组 | 编码器 ID | 转向驱动器 ID | 行走驱动器 ID |
| --- | ---: | ---: | ---: |
| 1 | `10` | `11` | `12` |
| 2 | `13` | `14` | `15` |
| 3 | `16` | `17` | `18` |
| 4 | `19` | `20` | `21` |

所有设备配置完成后，再接入同一条总线并搜索。正常情况下，FD 左侧列表中应能看到所有设备。

![FD integrated search](../reference/modules/sw69-ttl/assets/fd_13_cn.webp){ .img-rounded }

## 推荐调试流程

第一次调试一套新硬件时，可以按下面顺序执行：

```text
1. 只连接一个设备，确认供电和串口正常
2. 使用默认波特率搜索设备
3. 修改设备 ID
4. 重新搜索确认 ID 生效
5. 根据产品页面设置必要参数
6. 断电重启设备
7. 再次搜索并检查参数
8. 在调试页低速测试运动或读取反馈
9. 所有设备分别配置完成后，再接入同一条总线
10. 最后使用 SDK 或控制器程序进行联调
```

## 常见问题

### 扫描不到设备

请按顺序检查：

- COM 口是否选对。
- 串口是否已经点击 `打开`。
- 波特率是否与设备当前波特率一致。
- TTL Adapter (A) 是否被其它软件占用。
- USB 数据线是否支持数据传输。
- 设备是否接入外部电源。
- TTL 总线接口的 `S`、`+`、`-` 是否接线正确。
- 是否存在多个相同 ID 的设备同时接入。
- 是否使用了过长或接触不良的线缆。

### 能扫描到设备，但电机不动

请检查：

- 执行器是否接入外部电源，而不是只接了 USB。
- 当前运行模式是否适合该测试。
- 速度、加速度、电流或扭矩参数是否过低。
- 电机线是否连接正确。
- 是否触发限位、保护或心跳停止。
- 修改相位、运行模式等参数后是否已经断电重启。

### 修改 ID 后设备消失

通常是因为 FD 仍在用旧 ID 或旧波特率搜索。请尝试：

1. 停止搜索并重新搜索。
2. 确认当前波特率没有被一起修改。
3. 总线上只保留该设备。
4. 断电重启后再次搜索。

### 多个设备一起接入后通信不稳定

请检查：

- 所有设备 ID 是否唯一。
- 所有设备波特率是否一致。
- 电源容量是否足够。
- 大电流设备是否造成电压跌落。
- GND 是否共地。
- 总线线缆是否过长或分支过多。

多设备系统的供电和布线建议可参考 [总线设备分组供电与供电解耦](power-grouping-and-decoupling.md)。
