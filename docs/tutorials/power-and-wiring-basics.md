# 供电与接线基础

TTL 总线设备同时涉及通信和供电。很多通信问题实际来自供电不足、线序错误或 ID 冲突。

## TTL 总线三根线

常见 TTL 总线接口包含：

```text
+  电源正极
-  电源负极 / GND
S  单线 TTL 信号
```

接线前请确认接口方向和线序，不要只根据线材颜色判断。

## USB 不是执行器电源

TTL Adapter (A) 的 USB 通常只用于通信。部分低功耗设备可能可以通过 USB 完成读取或参数修改，但不建议仅依赖 USB 驱动执行器。

执行器类设备包括：

- 总线舵机
- 步进电机驱动器
- 轮式底盘驱动模块
- 机器人关节执行器

这些设备运行时应接入符合规格的外部电源。

## 电压要兼容所有设备

同一根总线上如果同时接入多个设备，应确认所有设备都支持当前总线电压。

例如：

- 5V 编码器可以接入 5V 总线。
- 12V 舵机应使用 12V 电源。
- 24V 步进驱动器应使用其允许范围内的电源。

!!! warning "不要把低压设备直接接到高压总线"
    如果某个设备只支持 5V，不应直接接到 12V 或 24V 总线。

## 分组供电

当系统中存在不同电压或大电流设备时，建议使用 Hub 或多个 Adapter 进行分组供电，让通信总线共享，但电源按设备类型分组。

## 上电前检查清单

- 电源电压是否在设备允许范围内。
- 电源电流是否有足够余量。
- 总线 `+ / - / S` 是否接反。
- 是否存在重复 ID。
- 步进电机线序是否正确。
- 限位开关是否接到正确接口。
