# TTL Node (A) Hardware Overview

The board provides USB communication, S.BUS input, two RGB LED groups, two PWM power outputs, and three connector families for the same single-wire TTL bus.

| Interface | Purpose |
| --- | --- |
| USB Type-C | Host communication and logic power |
| HX-5264-3P | TTL data, ground, and external bus power |
| PH2.0-3P | TTL data, ground, and external bus power |
| GH1.25-3P | TTL data and ground only |
| 2.54 mm 3-pin S.BUS | Receiver signal and 5 V receiver power |
| PH2.0-2P x2 | PWM-controlled load power |

The board measures 30 x 35 mm. Verify connector polarity and the silkscreen on the physical revision before making custom cables.
