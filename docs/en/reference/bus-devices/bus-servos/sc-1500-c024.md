# SC-1500-C024 Single-Shaft TTL Bus Servo

SC-1500-C024 is a 15kg.cm class single-shaft TTL serial bus servo. Its specification model is `SCS15-C024`. It uses a plastic housing, cored motor, brass gears, and ball bearings, making it suitable for medium-load single-output joints, grippers, pan-tilt mechanisms, and robot structures.

## Protection and Reliability

- Overload protection: triggers after load exceeds 80% of stall torque for 4s. Send a new position command to clear the overload flag.
- Voltage protection: the control-characteristics page in the source specification lists protection above 16V or below 4V; this Wiki still recommends operating within the 9-12.6V working range.
- Over-temperature protection: disables torque output above 70degC.
- Maximum position update rate: 1ms.
- Logic high: 2-5V.
- Logic low: 0-0.45V.
- Load life test: more than 50,000 cycles.
- Waterproofing: not waterproof.
