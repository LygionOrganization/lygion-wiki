# 3D3S Omnidirectional Chassis

3D3S Omnidirectional Chassis is an open chassis structure project. The Wiki currently provides the STEP model for reviewing the overall structure, checking installation space, and starting further mechanical design work.

## Usage Notes

- Check model units, assembly structure, and part interference in CAD before using the design.
- Before machining or purchasing parts, verify mounting holes, fasteners, cable clearance, and motion range against the actual hardware.
- Dimensions, BOM, controller selection, and load specifications are not stated here because they have not yet been confirmed in the source material.
