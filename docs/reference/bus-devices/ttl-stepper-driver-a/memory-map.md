# TTL Stepper Driver (A) 内存表与相位计算

本页整理 TTL Stepper Driver (A) 的常用内存地址、特殊功能字节，以及用于计算 `驱动器相位` 的网页工具。

TTL Stepper Driver (A) 使用 FT-SCS 自定义协议。出厂默认串口参数为：

```text
波特率：1 Mbps
数据位：8
校验位：无
停止位：1
默认 ID：1
```

如果某个地址的数据长度为 2 字节，低位字节在前，高位字节在后，也就是小端格式。

!!! warning "谨慎修改 EPROM 参数"
    EPROM 地址中的 ID、波特率、运行模式、相位等参数会影响设备通信和底层行为。修改前建议记录原值；如果通过程序写入，需要确认写入锁和掉电保存逻辑。

## 内存表分区

| 地址范围 | 分区 | 读写属性 | 用途 |
| --- | --- | --- | --- |
| `0x00~0x04` | 版本信息 | 只读 | 固件与驱动器版本 |
| `0x05~0x27` | EPROM 配置 | 读写 | ID、波特率、运行模式、相位、保护参数等 |
| `0x28~0x37` | SRAM 控制 | 读写 | 扭矩、加速度、目标位置、电流、速度等运行控制 |
| `0x38~0x43` | SRAM 反馈 | 只读 | 当前位置、当前速度、电压、温度、状态等反馈 |
| `0x53~0x56` | 出厂参数 | 只读 | 电流、速度、加速度限制与加速度倍数 |

## 特殊字节解释

### 驱动器相位 `0x12`

| bit | 权重 | 含义 | `0` | `1` |
| --- | --- | --- | --- | --- |
| BIT0 | 1 | 驱动方向相位 | 正向 | 反向 |
| BIT1 | 2 | 步数 M0 | 见 M2M1M0 编码 | 见 M2M1M0 编码 |
| BIT2 | 4 | 步数 M1 | 见 M2M1M0 编码 | 见 M2M1M0 编码 |
| BIT3 | 8 | 步数 M2 | 见 M2M1M0 编码 | 见 M2M1M0 编码 |
| BIT4 | 16 | 速度模式 | 速度 `0` 表示停止 | 速度 `0` 表示最高速度 |
| BIT5 | 32 | 限位 / 零点相位 | `0` 电平有效 | `1` 电平有效 |
| BIT6 | 64 | 目标电流相位 | 目标电流 `0` 表示默认电流 | 目标电流 `0` 表示 0 电流 |
| BIT7 | 128 | 心跳功能 | 关闭心跳功能 | 开启心跳功能 |

M2M1M0 编码：

| M2M1M0 | 相位值贡献 | 说明 |
| --- | --- | --- |
| `000` | `0` | 15 rpm |
| `001` | `2` | 7.5 rpm |
| `011` | `6` | 3.75 rpm |
| `100` | `8` | 0.94 rpm |
| `101` | `10` | 0.47 rpm |

### 驱动器状态 `0x41`

状态 bit 为 `0` 表示正常，`1` 表示异常。

| bit | 权重 | 含义 | 恢复条件 |
| --- | --- | --- | --- |
| BIT0 | 1 | 过压 / 欠压 | 电压恢复正常 |
| BIT1 | 2 | 目标超限 | 目标恢复正常 |
| BIT2 | 4 | 温度过热 | 温度恢复正常 |
| BIT3 | 8 | 过流触发，检测 FALT 低电平 | 打开扭矩开关恢复 |
| BIT4 | 16 | 自动限流 | 更新目标恢复 |
| BIT5 | 32 | 限位触发 | 限位开关联动和去抖后恢复 |
| BIT6 | 64 | 目标超限 | 目标恢复正常 |
| BIT7 | 128 | 零点触发 | 零点开关联动和去抖后恢复 |

### 卸载条件 `0x13`

卸载条件 bit 为 `0` 表示关闭，`1` 表示开启。

| bit | 权重 | 含义 |
| --- | --- | --- |
| BIT0 | 1 | 电压保护：关闭扭矩开关，电压恢复后自动恢复 |
| BIT1 | 2 | 保留 |
| BIT2 | 4 | 过热保护：关闭扭矩开关，温度恢复后自动恢复 |
| BIT3 | 8 | 保留 |
| BIT4 | 16 | 限流保护：无目标更新且电机停止运行时，自动降低输出电流至保护值 |
| BIT5 | 32 | 保留 |
| BIT6 | 64 | 限位保护：减速停止，反向远离后恢复 |
| BIT7 | 128 | 保留 |
