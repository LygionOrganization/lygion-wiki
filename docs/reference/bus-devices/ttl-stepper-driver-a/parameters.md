# TTL Stepper Driver (A) 参数说明

本页解释位置、速度、加速度和电流参数的含义。

## 位置参数

默认设置下：

```text
步进电机一圈 = 3200 微步
位置范围 = 0~65534
最大控制圈数 ≈ 65534 / 3200 ≈ 20.48 圈
```

如果需要更大多圈控制范围，可以修改角度分辨率参数。该参数取值范围通常为 `1~128`。

例如分辨率参数设置为 `3`：

```text
等效每圈步数 = 3200 / 3
最大控制圈数 ≈ 65534 / (3200 / 3) ≈ 61.44 圈
```

!!! note "控制范围与精度"
    提高角度分辨率参数可以扩大位置模式下的多圈控制范围，但位置控制精度会降低。

## 速度参数

默认情况下，速度参数单位为：

```text
50 微步 / 秒
```

RPM 换算：

```text
RPM = 速度参数 × 50 × 60 / 3200
```

例如速度参数为 `400`：

```text
400 × 50 × 60 / 3200 = 375 RPM
```

!!! tip "速度建议"
    第一次测试建议从 `100` 或 `200` 开始。速度过高可能导致失步、抖动或只响不转。

## 加速度参数

加速度参数单位为：

```text
100 微步 / 秒²
```

不建议第一次测试时把加速度设置为 `0`。

!!! warning "加速度为 0 的含义"
    加速度设置为 `0` 表示接近最高加速度，可能导致启动冲击、抖动或失步。建议根据负载设置一个较小但非 0 的加速度。

## 电流参数

TTL Stepper Driver (A) 设置的是电机绕组相电流，不是电源显示的输入电流。

估算关系：

```text
相电流 ≈ 3.3 × 2 × (参数 / 1000)
```

例如参数为 `200`：

```text
相电流 ≈ 3.3 × 2 × 0.2 = 1.32A
```

## 为什么电源电流和设置不同

电源表显示的是母线输入电流，受输入电压、电机阻抗、电机电感、转速、负载、细分设置和驱动效率影响。因此它通常不等于设置的相电流。
