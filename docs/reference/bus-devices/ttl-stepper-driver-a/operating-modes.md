# TTL Stepper Driver (A) 运行模式

TTL Stepper Driver (A) 常用运行模式包括位置模式、速度模式和从动同步模式。

## 模式概览

| 模式 | 名称 | 典型用途 |
| --- | --- | --- |
| Mode 0 | 位置模式 | 控制电机转到指定位置 |
| Mode 1 | 速度模式 | 控制电机连续正转、反转或停止 |
| Mode 2 | 从动同步模式 | 通过 EDS 接口让从设备跟随主设备 |

!!! note "更改模式"
    你可以使用 FD 软件更改运行模式，也可以参考产品的内存表和 EPROM 相关的例程，使用程序来更改运行模式。

!!! warning "EDS接口 与 断电重启"
    更改运行模式前，不要连接 EDS 接口，避免损害从动设备。
    
    更改模式后，需要断电重启后才可以正常使用。

## 位置模式

位置模式用于让电机运动到指定目标位置。

典型函数：

```python
packetHandler.WritePosEx(ID, position, speed, acc, current)
```

参数含义：

| 参数 | 含义 |
| --- | --- |
| `ID` | 设备 ID |
| `position` | 目标位置 |
| `speed` | 速度参数 |
| `acc` | 加速度参数 |
| `current` | 目标相电流参数 |

适合场景：

- 转台
- 机械臂关节
- 滑台
- 夹爪
- 丝杆机构

## 速度模式

速度模式用于连续运行。

```python
packetHandler.WheelMode(ID)
packetHandler.WriteSpec(ID, speed, acc, current)
```

速度方向：

```text
speed > 0：正向旋转
speed < 0：反向旋转
speed = 0：停止
```

!!! warning "速度模式建议开启心跳保护"
    速度模式下，如果上位机程序异常或通信中断，电机可能持续运行。建议配置心跳保护。

    心跳保护开启后，设备在某一段时间内没有接收到新的指令，会自动停止转动。

## 从动同步模式

从动同步模式适合多个步进电机需要在底层保持同步的场景，例如：

- 多丝杆升降平台
- 双电机同步驱动
- 并联机构
- 多轴同步机构

!!! tip "更可靠的限位"
    多个电机采用从动同步模式控制时，如果需要使用限位开关，限位开关需要接在主设备上。

    当主设备的限位开关被触发后，停止动作也可以同时作用于从设备。

    这是一种从底层实现的限位控制，不依赖应用层程序，更加稳定可靠。

使用流程：

1. 将从设备的运行模式设置为 2
2. 设置从设备的副 ID，使其副 ID 与主设备 ID 相同
3. 使用 GH1.25-3P 线连接 EDS 同步接口
4. 后续只控制主设备 ID，从设备自动跟随

!!! note "避免主 ID 重复"
    之前文章内所提到的 ID，都是设备的主 ID，总线上**不可以**出现相同的主 ID。

    通过 FD 软件或 SDK，将从设备的从 ID 改为与主设备的主 ID 相同，总线上**允许**多个设备使用相同的从 ID。

## 与总线同步写的区别

| 方式 | 特点 |
| --- | --- |
| 总线 SyncWrite | 上位机一次性向多个设备发送目标参数 |
| EDS 从动同步 | 从设备在底层跟随主设备，适合强同步机械结构 |

对于多丝杆升降等强同步场景，EDS 从动同步更可靠。
