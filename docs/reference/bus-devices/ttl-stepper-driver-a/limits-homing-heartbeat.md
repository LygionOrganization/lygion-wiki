# TTL Stepper Driver (A) 限位、回零与心跳保护

## 限位接口

TTL Stepper Driver (A) 有两个限位接口：

```text
MIN
LIMIT
```

每个限位接口包含：

```text
S / + / -
```

当 `S` 引脚被拉高时，触发对应限位。

## 机械限位开关

常见机械限位开关可使用常开接法：

```text
限位开关一端接 S
限位开关另一端接 +
```

按下限位开关时，`S` 被拉高。

## PNP 光电 / 金属感应限位

```text
正极接 +
负极接 -
信号线接 S
```

## 不同模式下的限位逻辑

| 模式 | MIN | LIMIT |
| --- | --- | --- |
| 位置模式 Mode 0 | 通常不作为主要位置限位 | 限制向更大目标位置运动 |
| 速度模式 Mode 1 | 限制负方向运动 | 限制正方向运动 |

限位触发后，通常允许电机反向离开限位位置。

## 速度模式回零流程

对于丝杆、滑台等机构，可以使用速度模式完成回零。

```text
1. 开机后进入速度模式
2. 给电机一个向 MIN 方向的速度
3. MIN 限位触发后停止
4. 使用 reOfsCal() 将当前位置设置为 0
5. 切换回位置模式
6. 后续使用位置模式控制
```

## 心跳保护

心跳保护用于速度模式安全保护。如果上位机长时间没有发送新的控制指令，电机会自动停止。

心跳保护时间单位：

```text
100 ms
```

例如设置为 `30`：

```text
30 × 100 ms = 3000 ms = 3 秒
```

!!! warning "速度模式建议开启心跳保护"
    速度模式下，如果程序异常、通信中断或主控掉线，电机可能持续运行。建议配置心跳保护。
