# TTL Stepper Driver (A) FAQ

## Q1：可以 ping 成功，但电机不转怎么办？

请检查：

- 是否接入外部 DC 9~26V 电源。
- 步进电机线序是否正确。
- 电机是否为双极步进电机。
- 电流参数是否过低。
- 运行模式是否正确。
- 是否触发限位。
- Torque 是否关闭。
- 负载是否过大。

## Q2：电机只响不转或容易失步怎么办？

常见原因：

- 速度参数过高。
- 加速度参数过高或设置为 `0`。
- 电流参数过低。
- 输入电压偏低。
- 电机绕组电感较高，高速性能不足。
- 负载惯量过大。

建议：

1. 降低速度参数。
2. 设置较小但非 0 的加速度。
3. 适当提高电流参数。
4. 空载测试确认驱动正常。
5. 再逐步增加负载。

## Q3：为什么电源显示电流和设置电流不同？

驱动板设置的是电机相电流，不是电源输入电流。电源显示的是母线电流，会受到输入电压、电机阻抗、转速、负载和驱动效率影响。

## Q4：速度参数如何理解？

默认单位为：

```text
50 微步 / 秒
```

RPM 换算：

```text
RPM = 速度参数 × 50 × 60 / 3200
```

## Q5：位置模式为什么默认约 20.5 圈？

默认一圈为 3200 微步，位置范围为 `0~65534`：

```text
65534 / 3200 ≈ 20.48 圈
```

需要更大范围时，可修改角度分辨率参数，但精度会降低。

## Q6：可以和总线舵机或 TTL Encoder E02 接在一起吗？

可以。注意：

- ID 不能重复。
- 波特率需要一致。
- 总线电压需要兼容所有设备。
- 总线设备较多时，需要保证供电稳定。

## Q7：同步控制如何选择？

一般多设备同时启动可使用 SyncWrite。多丝杆升降、双电机强同步等场景，优先考虑 EDS 从动同步。
