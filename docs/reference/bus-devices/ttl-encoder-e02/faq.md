# TTL Encoder E02 FAQ

## Q1：读取不到编码器怎么办？

请检查：

- 串口名称是否正确。
- 波特率是否为设备实际波特率。
- 设备 ID 是否正确。
- HC-1.25-3P 线序是否正确。
- 总线供电是否正常。
- 同一根总线上是否存在重复 ID。

## Q2：角度数据跳动怎么办？

优先检查机械安装：

- 径向磁铁是否对准编码器 IC 中心。
- 磁铁与 IC 表面距离是否约 1mm。
- 磁铁是否固定牢靠。
- 旋转轴是否偏心或晃动。
- 编码器 PCB 是否松动。

## Q3：为什么示例代码里出现 TTLSD 或 motor？

TTL Encoder E02 与 TTL Stepper Driver (A) 复用了部分 SDK 接口。对于编码器，只需要使用读取位置、读取速度、同步读取和基准设置相关函数。

## Q4：可以和总线舵机接在一起吗？

可以。TTL Encoder E02 可以与兼容的 Feetech TTL 总线舵机、TTL Stepper Driver (A) 等设备接入同一根 TTL 总线。

注意：

- ID 不能重复。
- 波特率需要一致。
- 总线电压需要兼容所有设备。

## Q5：校准后重新上电还需要重新设置吗？

单圈基准校准结果会掉电保存，通常不需要重新设置。但多圈累计圈数不掉电保存。
