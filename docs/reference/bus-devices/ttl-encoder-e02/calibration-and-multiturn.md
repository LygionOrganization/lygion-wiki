# TTL Encoder E02 校准与多圈

## 设置当前位置基准

当前位置基准设置不是简单清零，而是把编码器当前实际角度设置为指定的位置值。

Python 示例：

```python
packetHandler.reOfsCal(1, 1024)
```

含义：将 ID 1 编码器当前位置设置为 1024。

C++ 示例：

```cpp
ttlsd.CalibrationOfs(1, 1024);
```

## 常用位置值

| 位置值 | 角度 |
| --- | --- |
| 0 | 0° |
| 1024 | 90° |
| 2048 | 180° |
| 3072 | 270° |
| 4095 | 接近 360° |

## 校准结果是否保存

TTL Encoder E02 的基准校准结果会掉电保存。重新上电后，编码器仍会使用该基准。

## 多圈数据

TTL Encoder E02 支持多圈读取，最大位置范围为：

```text
0~65534
```

在 12bit 精度下，对应约 16 圈。

!!! warning "多圈圈数不掉电保存"
    编码器可以掉电保存单圈绝对角度基准，但多圈累计圈数掉电后不保存。若应用依赖多圈圈数，需要由上位机或主控程序重新建立多圈位置基准。

## 典型应用

- 将机械零位设置为 `0`
- 将关节中位设置为 `2048`
- 将装配后的某个姿态设置为指定角度
- 多个编码器装配后统一校准参考位置
