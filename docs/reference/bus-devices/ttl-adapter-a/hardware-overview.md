# TTL Adapter (A) 硬件概览

TTL Adapter (A) 集成 USB、UART、单线 TTL 总线和外部供电接口。

## 板载资源

![Board Resources](../../../assets/images/ttla02.png){ .img-rounded width="600" }

| 编号 | 资源 | 用途 |
| --- | --- | --- |
| 1 | HX-5264-3P TTL 总线接口 | 连接 TTL 总线设备、舵机、驱动板 |
| 2 | GH1.25-3P 板间通信接口 | 多板串联、通信扩展 |
| 3 | UART RX / TX / GND | 连接 ESP32、STM32、Arduino 等 MCU |
| 4 | USB Type-C | PC 通信、参数配置、SDK 调试 |
| 5 | DC5521 供电接口 | 外部电源输入 |
| 6 | 通信状态指示灯 | 显示通信状态 |
