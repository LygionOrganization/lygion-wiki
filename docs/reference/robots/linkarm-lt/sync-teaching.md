# ESP-NOW 同步示教

ESP-NOW 可让一台 LinkArm-LT 作为示教主机，将关节姿态实时广播给一台或多台从机。通信不依赖路由器，适合教学演示和多机械臂同步。

!!! danger "从机可能突然快速动作"
    开启接收时，从机会移动到初始位置或立即追随主机姿态。固定所有机械臂，清空工作区域，并让人员远离夹爪、连杆和眼睛。

## 工作模式

| OLED 状态 | 含义 |
| --- | --- |
| `ESP-NOW [OFF]` | 不接收 ESP-NOW 指令 |
| `ESP-NOW [ON] KnownMAC` | 只接收已添加主机的指令 |
| `ESP-NOW [ON] BRD MAC` | 接收广播指令 |
| `BRD Leader [ON]` | 本机正在广播关节位置 |

设备的 MAC 地址显示在 OLED 和 Web 控制台中，每台设备都不同。

## 配置主机

1. 在默认界面长按五向开关“上”，释放关节扭矩锁。
2. 用手缓慢摆动机械臂，保持在安全姿态。
3. 长按“左”，开启关节位置广播。
4. OLED 显示 `Leader BRD [ON]` 后，主机配置完成。

主机操作：

- 长按“右”：关闭广播。
- 长按“下”：重新打开扭矩锁并恢复初始状态。

## 配置广播从机

1. 长按“左”，开启 ESP-NOW 接收，此时默认为已知 MAC 模式。
2. 再次长按“左”，切换为广播接收模式。
3. 从机会迅速追随主机姿态。
4. 长按“右”可关闭 ESP-NOW 接收。

后续长按“左”可在 `KnownMAC` 与 `BRD MAC` 之间切换。

## 绑定指定主机

为了避免从机响应附近其他设备，建议将主机 MAC 添加到从机 Peer 列表：

```json
{"T":414,"mac":"FC:01:2C:DA:5F:FC"}
```

把示例 MAC 替换为主机 OLED 显示的实际地址，再让从机使用 `KnownMAC` 模式。

### 开机自动添加主机

可把添加 Peer 的指令写入 `boot.mission`：

```json
{"T":303,"name":"boot","json":"{\"T\":414,\"mac\":\"FC:01:2C:DA:5F:FC\"}"}
```

!!! note "广播模式和已知 MAC 模式"
    广播模式配置简单，但同一范围内的其他主机也可能控制从机。已知 MAC 模式更适合固定设备组合。

## 退出同步示教

1. 从机长按“右”，关闭 ESP-NOW 接收。
2. 主机长按“右”，关闭位置广播。
3. 主机长按“下”，恢复扭矩锁。
4. 确认 OLED 均显示 ESP-NOW 或 Leader 为 `OFF`。
