# LinkArm-LT 故障排查

## 机械臂无法稳定站立

LinkArm-LT 不能在未固定状态下运行。使用两只 G 字夹固定到桌面，或使用安装孔固定到刚性底盘。两只夹具应尽量分开。

## 开机后机械臂突然动作

可能原因：

- 存在 `boot_user.mission` 开机任务
- 设备处于 ESP-NOW 从机模式
- 局域网内有程序通过 HTTP 或 WebSocket 控制
- 校准文件缺失，设备进入校准流程

先断开网络或关闭控制程序，确保机械臂固定，再检查 OLED、RGB 和任务文件。

## RGB 黄灯常亮

通常表示中位校准文件缺失。常见于刷机、格式化文件系统或全片擦除之后。按照[中位校准](firmware-and-calibration.md#midpoint-calibration)重新设置。

## Web 控制台打不开

1. 确认电脑或手机仍连接 `Robot` 热点。
2. 忽略“无互联网”提示，不要让系统自动切换到其他网络。
3. 访问 `http://192.168.4.1`，不要使用 HTTPS。
4. 如果使用 STA 模式，确认终端和机械臂在同一局域网。
5. 从 OLED 读取最新 IP，路由器可能在重启后重新分配地址。

## 忘记热点名称或密码

开机时 OLED 第一行会显示实际 AP SSID。页面输入框显示的是默认值，不一定是当前保存值。

若完全无法连接，可考虑清理 NVS：

```json
{"T":601}
```

执行前应确认仍有 USB CDC 或其他可用控制入口。

## Web 控制动作格外缓慢

检查总线是否有设备断链。LinkArm-LT 默认需要以下 5 个总线设备正常通信：

- 舵机 ID 31
- 舵机 ID 32
- 舵机 ID 33
- 舵机 ID 34
- TTL Node (A) ID 40

Ping 不通的设备可能造成等待和阻塞。

## 仅连接 USB 时舵机无力或复位

USB 只适合控制器通信和调试。请接入 DC 9~12.6V、至少 3A 的动力电源，并把底座开关拨到 `ON`。

## 安装到移动底盘后如何供电

可使用满足功率要求的 3S 锂电池：

- 标称电压约 11.1V
- 满电电压 12.6V
- 产品最低工作电压约 9V

同时确认电池放电能力、保险、线径和连接器能够覆盖峰值电流。

## USB CDC 无法连接

- 确认使用中间的 `USB` 接口，而不是 `UART`。
- 更换支持数据传输的 USB 线。
- 关闭 YAT、串口监视器等占用端口的软件。
- Windows YAT 测试时勾选 `DTR on`。
- Linux 检查串口权限。

## HTTP 或 WebSocket 连接失败

| 现象 | 处理 |
| --- | --- |
| `ConnectionError` | 检查 IP 和 Wi-Fi |
| `Timeout` | 检查信号、防火墙和设备是否卡死 |
| HTTP 404 | 使用 `/api/cmd` |
| WebSocket refused | 使用端口 `80` 和路径 `/ws` |
| WebSocket 无反馈 | 确认固件已启用对应状态上报 |

## 动作脚本无法运行

- 每行只放一条 JSON。
- 使用英文标点。
- 检查 JSON 是否有效。
- 确认任务名称不包含 `.mission` 后缀。
- 先逐条发送验证坐标和参数。
- 使用 `STOP MISSION` 或 `{"T":0}` 中断异常任务。

## 从机不跟随 ESP-NOW 主机

1. 确认主机显示 `Leader BRD [ON]`。
2. 确认从机显示 `ESP-NOW [ON]`。
3. 使用已知 MAC 模式时，检查主机 MAC 是否正确加入 Peer。
4. 尝试广播模式判断是否为 MAC 配置问题。
5. 检查两台设备距离与无线干扰。

## 刷机后姿态异常

Factory 刷机通常会删除 `boot.mission` 中的中位校准。立即停止动作并执行[固件恢复与中位校准](firmware-and-calibration.md)中的校准步骤。
