# LinkArm-LT JSON 指令参考

LinkArm-LT 的 Web 控制台、USB CDC、HTTP 和 WebSocket 共用同一套 JSON 指令。字段 `T` 表示命令类型。

!!! warning "先从低速和安全姿态测试"
    坐标控制指令会立即引发机械臂动作。发送前固定机械臂、清空工作区域，并确认目标位置可达。

## 发送方式

- Web 控制台：在 `JSON INTERFACE` 输入单条指令并点击 `SEND`。
- USB CDC：发送一行 JSON，并以换行符结束。
- HTTP：向 `http://<设备IP>:80/api/cmd` 发送 JSON POST 请求。
- WebSocket：连接 `ws://<设备IP>:80/ws` 后发送 JSON 字符串。

## 机械臂控制

### 关节角度

```json
{"T":134,"ang":[0,0,0,0]}
```

`ang` 为舵机 ID 31、32、33、34 对应的四个关节角度。

### 关节弧度

```json
{"T":135,"rad":[0,0,0,0]}
```

### 三维坐标快速控制

```json
{"T":136,"xyzg":[260.5,0,122.38,50]}
```

| 参数 | 含义 |
| --- | --- |
| `x` | 正前方为正 |
| `y` | 左侧为正 |
| `z` | 上方为正 |
| `g` | 夹爪角度，`0` 闭合，`50` 最大张开 |

该指令无轨迹插值，会直接运动到目标位置。连续控制时建议由上位机自行插值。

### FPV 快速控制

```json
{"T":137,"rbzg":[260.5,0,122.38,50]}
```

| 参数 | 含义 |
| --- | --- |
| `r` | 末端水平伸出距离，不可为负 |
| `b` | 底座旋转角度，正值向右 |
| `z` | 末端高度 |
| `g` | 夹爪角度 |

### 三维坐标平滑控制

```json
{"T":138,"xyzg":[236.5,0,122.38,0],"spd":0.4}
```

使用插值和柔性启停，使末端沿直线移动。该指令执行期间会阻塞，持续时间取决于距离与速度。

### FPV 平滑控制

```json
{"T":139,"rbzg":[236.5,0,122.38,0],"spd":0.4,"br":200}
```

`br` 用于底座旋转速度比例。

### 反馈与连续控制

| 指令 | 说明 |
| --- | --- |
| `{"T":140,"spd":1.2}` | 设置最大关节速度 |
| `{"T":141}` | 获取关节反馈弧度 |
| `{"T":142}` | 获取关节目标弧度 |
| `{"T":143}` | 获取当前 XYZG |
| `{"T":144}` | 获取当前 RBZG |
| `{"T":145,"flag":1,"hz":10}` | 开启 USB CDC 关节与负载反馈 |
| `{"T":146,"flag":0,"axis":0,"delta":0.01}` | 连续轴控制设置 |
| `{"T":147}` | 执行关节校准 |

## 单个舵机

| 功能 | JSON |
| --- | --- |
| 控制舵机 | `{"T":31,"id":1,"pos":511,"time":0,"spd":0}` |
| 修改 ID | `{"T":33,"old_id":1,"new_id":2}` |
| 扭矩锁 | `{"T":34,"id":1,"state":1}` |
| 读取位置 | `{"T":35,"id":1}` |
| 限制转矩 | `{"T":119,"id":34,"limit":500}` |

`limit=1000` 表示不限制，`500` 约为 50% 转矩。可通过限制 ID 34 来降低夹爪力量，但也可能影响速度。

## 延时、灯光与显示

### 延时

```json
{"T":51,"delay":1000}
```

单位为毫秒。

### TTL Node (A) RGB

```json
{"T":200,"id":40,"set":[1,255,0,0]}
```

设置单组灯，`set` 为灯编号、R、G、B。TTL Node (A) 默认 ID 为 `40`，灯编号为 `1` 和 `2`。

```json
{"T":201,"id":40,"set":[255,0,0]}
```

同时设置两组灯。颜色通道为 8 级，推荐值为 `0`、`31`、`63`、`95`、`127`、`159`、`191`、`223`、`255`。

### OLED

```json
{"T":202,"line":1,"text":"Hello, world!","update":1}
```

| 指令 | 说明 |
| --- | --- |
| `{"T":203}` | 刷新 OLED |
| `{"T":204,"l1":"Line 1","l2":"Line 2","l3":"Line 3","l4":"Line 4"}` | 一次更新四行 |
| `{"T":205}` | 清空 OLED |

### 蜂鸣器

```json
{"T":206,"freq":1000,"duration":1000}
```

频率单位为 Hz，持续时间单位为毫秒。

## 无线配置

### Wi-Fi

```json
{"T":400,"mode":1,"ap_ssid":"Robot","ap_password":"12345678","channel":1,"sta_ssid":"ssid","sta_password":"password"}
```

修改后请记录新的 AP 信息，避免失去设备连接入口。

### ESP-NOW

| 功能 | JSON |
| --- | --- |
| 开关接收 | `{"T":411,"mode":1}` |
| 添加 Peer | `{"T":414,"mac":"FC:01:2C:DA:5F:FC"}` |
| 添加广播地址 | `{"T":414,"mac":"FF:FF:FF:FF:FF:FF"}` |

向 Peer 发送嵌套 JSON 时，内部双引号需要转义：

```json
{"T":413,"mac":"FC:01:2C:DA:5F:FC","data":"{\"T\":206,\"freq\":500,\"duration\":30}"}
```

## 系统设置

| 功能 | JSON | 注意事项 |
| --- | --- | --- |
| 重启 | `{"T":600}` | 设备立即重启 |
| 清理 NVS | `{"T":601}` | 可用于处理 Wi-Fi / ESP-NOW 配置异常 |
| 格式化文件系统 | `{"T":602}` | 会删除任务和校准文件 |
| 消息输出 | `{"T":604,"echo":1,"uart":0,"usb":1}` | 设置回声、UART 和 USB 日志 |
| 串口透传 | `{"T":605,"sf":1}` | 将 UART 接口用于总线设备调试 |
| 中断任务 | `{"T":0}` | 停止当前任务执行 |

!!! danger "谨慎使用格式化"
    `T=602` 会清空文件系统，包括中位校准和任务文件。执行后通常需要重新完成[中位校准](firmware-and-calibration.md#midpoint-calibration)。

## 任务文件 { #mission-files }

| 功能 | 示例 |
| --- | --- |
| 创建任务 | `{"T":301,"name":"mission1","intro":"demo"}` |
| 末尾追加指令 | `{"T":303,"name":"mission1","json":"{\"T\":51,\"delay\":1000}"}` |
| 插入指令 | `{"T":304,"name":"mission1","step":2,"json":"{\"T\":51,\"delay\":1000}"}` |
| 替换指令 | `{"T":305,"name":"mission1","step":2,"json":"{\"T\":51,\"delay\":500}"}` |
| 删除步骤 | `{"T":306,"name":"mission1","step":2}` |
| 运行步骤 | `{"T":307,"name":"mission1","step":2}` |
| 运行任务 | `{"T":308,"name":"mission1","interval":1000,"loop":1}` |
| 删除任务 | `{"T":309,"name":"mission1"}` |

`loop=-1` 表示无限循环。嵌套在 `json` 字段内的指令必须转义双引号。

## 同步控制扩展

固件还提供多舵机同步控制命令：

| `T` | 用途 |
| ---: | --- |
| `16` / `17` | STS/STSM 系列同步控制 |
| `26` / `27` | HLS 系列同步控制 |
| `36` / `37` | SCS 系列同步控制 |
| `180` | 四路轮毂电机控制 |

这些命令面向二次开发。使用前应核对目标设备系列、ID、位置范围和供电规格。
